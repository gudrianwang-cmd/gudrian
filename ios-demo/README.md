# 高铁探秘（iOS Demo）

一个用 SwiftUI 写的 CRH2A 型动车组科普小 App，配合仓库里的《中国CRH2A型高铁探秘》PPT。

## 功能

- **首页**：CRH2A 核心数据（设计时速、编组、定员、牵引功率）和 8 节车厢动车/拖车示意
- **知识卡**：6 张知识卡片，点开看详细介绍
- **开动**：拖动油门滑块，列车跑起来，并算出北京到上海要几个小时
- **小测验**：5 道选择题，答完给出成绩

## 怎么运行

`CRHExplorer.swiftpm` 是 Swift Playgrounds 应用包，需要 iOS 17：

- **Mac**：双击用 Xcode 15 或更新版本打开，选一个 iPhone 模拟器，点运行（⌘R）
- **iPad**：用 Swift Playgrounds 4.4 或更新版本打开，点运行

`preview.html` 是网页版模拟预览，用浏览器直接打开就能看到大致效果。
